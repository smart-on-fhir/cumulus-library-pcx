# PCX workplan

Ordered work items for `cumulus-library-pcx`, derived from the [2026-09-11 code review](reviews/code-review-2026-09-11/REVIEW.md) and the open findings of the earlier reviews. Phases map onto the delivery milestones in [limitations.md](limitations.md): phase 1 and 2 unblock **feasibility**, phases 3 and 4 serve **trial-aligned descriptive reproduction**, phase 5 is hygiene that can ride along. Within a phase the items are in the order they should land, because later items depend on earlier ones or change tables the earlier ones create.

Conventions for every item: no hand edits to generated files (CSV or template → generator → `athena/*.sql` and `*.toml`); fail-fast SQL; no `;` inside SQL comments; one statement per file; add or extend a DuckDB test in `tests/` for every SQL change; regenerate and diff before committing. "Closes" names the finding ids: F = 2026-09-09 review, § = 2026-09-10 LLM review, W = 2026-09-11 QA review, R = 2026-09-11 code review.

Severity is the effect on the ACNS0334 emulation: **blocker** stops the build, **high** changes who is in a cohort or an outcome value, **medium** changes a column or a test, **low** is maintainability.
